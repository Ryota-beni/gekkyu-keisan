# 月給計算

掛け持ちの日払い・都度払いの給料を、もらった都度いれて、その月の合計を出すアプリ。

- 単一ファイルの静的サイト（`index.html`）＋ PWA（ホーム画面に追加してオフラインでも動く）
- データはブラウザの `localStorage` にだけ保存。サーバーには何も送らない
- ビルド不要。`index.html` を直接ひらけば動く

## 月の締めルール

**毎月1日の 12:00 より前に記録したものは、前の月の合計に入る。**

夜中に仕事が終わって日付をまたいでから入力しても、前の月に入る。
たとえば 9/1 の 04:00 に記録した分は 8 月に計上され、9/1 の 15:00 に記録した分は 9 月に計上される。

締め時刻は設定でいつでも変えられる（変えると過去の記録も、そのルールで計算しなおされる）。

実装は「記録の日時から締め時刻ぶん巻き戻した日付の年月」＝計上月、という一行のルールで統一している（`monthOf()`）。

## データ

```jsonc
{
  "v": 1,
  "jobs":    [{ "id": "…", "name": "居酒屋A", "color": "#0ea5e9", "archived": false }],
  "entries": [{ "id": "…", "ts": 1756000000000, "jobId": "…", "amount": 12000 }],
  "cutoffMin": 720   // 締め時刻（0:00 からの分）。720 = 12:00
}
```

- `ts` は実際にもらった日時（エポックms）。計上月は保存せず、表示のたびに計算する
- 記録のある職場を削除すると `archived: true` になり、過去の記録には名前が残る
- 設定 → 書き出し / 読み込み で JSON をバックアップできる

## ローカルで動かす

```sh
python3 -m http.server 4321
# → http://localhost:4321
```

Service Worker を動かすには `http://` で開く必要がある（`file://` だとオフライン機能だけ無効になる）。

## デプロイ

静的ホスティングにそのまま置くだけ。Vercel なら:

```sh
vercel        # プレビュー
vercel --prod # 本番
```

`sw.js` の `CACHE` の値（`gekkyu-v1`）を更新すると、古いキャッシュが捨てられる。
